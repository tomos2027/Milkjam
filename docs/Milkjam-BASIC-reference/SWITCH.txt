SWITCH
Milkjam Basic
-----------------------------------------------------------
[ 機能 ]
映像出力を切り替えます。

[ コマンド 書式 ]
SWITCH {<モード>{,<回転>}}

[ 例 ]
SWITCH
SWITCH 1
SWITCH 2,1
SWITCH 3

[ 解説 ]
映像出力を切り替えます。<モード> の値は次のとおりです。

    0  DVI (HDMI) 出力 720x480p60 (TV 互換 480p)
       GP12-19 (Pico DVI sock)
    1  NTSC コンポジット出力 (カラー対応)
       GP3 (75Ω+560pF の外部回路経由)
    2  TFT 液晶 ILI9341 出力 (白黒)
       GP12-16 (HDMI ピンと排他 → LCDON/LCDOFF で管理)
    3  WEB 表示 (NTSC 出力を継続しつつ WiFi AP (親機) として
       動作し、ブラウザ (http://192.168.4.1) にも同じ画面を表示、
       キー入力もブラウザから受け付ける)

<モード> を省略すると DVI→NTSC→TFT→WEB→DVI の順で
切り替えます (LCDON/LCDOFF で禁止されているモードはスキップ)。

SWITCH 2 の場合は第 2 引数で TFT の向きを指定できます。
1 で 180° 回転、0 で通常向きに戻ります。

SWITCH 3 の場合は画面に AP 名と URL を表示します
(AP 名・パスワードは EJ "SETAPSSID" / "EJ "SETAPPASS" で変更可、
URL は http://192.168.4.1 固定)。SWITCH 3 を再入力した場合も
AP 名と URL を表示します。SWITCH 0～2 へ戻すと AP は停止し、
家の WiFi (保存済み SSID) があれば自動再接続します。

モードと回転設定はフラッシュに保存され、
次回起動時も同じモードで起動します。
NTSC・WEB モードは CPU が 157.5MHz 駆動のため、
DVI・TFT (270MHz) より BASIC の実行速度が遅くなります。
TFT と SD カードは SPI1 を共用するため、
SDON 中 (SD 読み書き中) は画面更新が一時停止します。

LCDON・LCDOFF を参照して下さい。
